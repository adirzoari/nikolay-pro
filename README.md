# ניקולאי — מערכות מיזוג אוויר

אתר Next.js + React + TypeScript עם ייצוא סטטי ותמיכה בעברית, אנגלית, רוסית, ערבית, אמהרית, טיגרית וספרדית.

## הפעלה ובנייה

```bash
npm ci
npm run dev
```

לבנייה: `npm run build`. התוצאה בתיקיית `out`, לפריסה באחסון סטטי עם תמיכה בכתובות ללא סיומת. `next start` אינו מתאים לייצוא סטטי. אין צורך במשתני סביבה.

## תוכן ושפות

- `app/views/` — עמוד הבית, פרויקטים, תעודות ומדריך עם רשימת הכנה לטכנאי.
- `app/components/SiteHeader.tsx` — ניווט ובחירת שפה.
- `app/components/ProcessJourney.tsx` — תהליך העבודה המחובר.
- `app/i18n/messages.ts` ו־`extra-messages.ts` — מילוני תרגום; כל רשומה כוללת את שבע השפות באותו סדר.
- `app/i18n/config.ts` — שפות, כיווניות וקישורים.
- `app/[[...path]]/page.tsx` — יצירת 28 עמודים סטטיים: ארבעה עמודים בכל שפה. עברית בשורש, שאר השפות תחת קוד השפה.
- `app/globals.css`, `inner.css`, `refinements.css` — עיצוב ורספונסיביות.
- `app/dark.css` — ערכת המצב הכהה. כל הכללים תחת `html[data-theme="dark"]`, כך שהמצב הבהיר אינו משתנה. הבחירה נשמרת ב־`localStorage` תחת `nikolai-theme`, וסקריפט קצר ב־`app/[[...path]]/layout.tsx` קובע את התכונה לפני הציור הראשון כדי למנוע הבהוב. ללא בחירה שמורה נקבעת ברירת המחדל לפי `prefers-color-scheme`. המתג נמצא ב־`app/components/ThemeToggle.tsx`.
- `public/images/` — נכסי תמונה, כולל דיוקן חדש לאודות.

התרגומים נכללים ב־HTML הראשוני, כולל טקסטים נפתחים. בעת הוספת טקסט, הוסיפו מפתח עם שבעה תרגומים והשתמשו ב־`t()`. פרמטרים משתמשים ב־`{0}`, `{1}` וכן הלאה. התמונות עשויות להכיל כיתוב מקורי שאינו חלק ממילוני הטקסט.

## SEO

`app/seo.ts` מגדיר כותרות ותיאורים לכל שפה, canonical, hreflang ונתונים מובנים. `app/sitemap.ts` כולל 21 כתובות; עמודי התעודות מסומנים noindex משום שהמסמכים עדיין להמחשה. לאחר החלפתם במסמכים אמיתיים אפשר להסיר הגבלה זו ולהוסיפם למפה. בשינוי דומיין עדכנו את `origin`.

גישה המחייבת התחברות מונעת סריקה ציבורית. קובצי robots ו־sitemap אינם משנים הרשאות גישה ואינם מבטיחים אינדוקס או דירוג.

## פניות ונכסים

טופס הפנייה ורשימת ההכנה פותחים טיוטת WhatsApp; המבקר משלים את השליחה בעצמו. אין מסד נתונים או שליחת אימייל. לעדכון הטלפון חפשו `0523322821` ו־`972523322821`.

תמונות הפרויקטים והתעודות זמניות, כמצוין באתר. אין דירוגים או המלצות מומצאים. גופנים נטענים מ־Google Fonts עם גיבוי מקומי.

## בדיקות

```bash
npm run build
node scripts/validate-site.cjs
```

הבנייה בודקת TypeScript. הבדיקה הנוספת מאמתת כיסוי תרגומים, פרמטרים, 28 עמודים, כיווניות, כותרות, canonical, hreflang, נתונים מובנים, תמונות ומפת אתר. היא אינה תחליף לעריכה לשונית של דוברי השפות או לבדיקת דפדפן.
